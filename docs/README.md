## 一条关于「文档也会静默失效」的说明

这个仓库里同一件事往往有两份记录：**当时的过程**与**后来收敛的结论**。两者都该留，但**必须分得开** —— 否则读的人会：

- 拿一份被取代的方案当现状
- 或者以为某条调研已经落地，而它其实只在笔记里

第二条真的发生过：写[落地对照](调研落地对照-2026-10-14.md)时，回指一遍揪出**四条「以为落了、其实没落」**。

**所以这份索引不只是目录，它是一次分类。** 新增文档时，想清楚它属于哪一层再放进来。
